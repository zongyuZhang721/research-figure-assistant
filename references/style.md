# 视觉规范

沿用已经多轮调整的克制、紧凑科研风格；并非任何期刊官方认证模板。

|用途|色值|辅助编码|
|---|---|---|
|主要趋势；Protection；Rerouting|#167D9A|实线/圆点；Rerouting斜线|
|对照；Transfer；Recovery|#C87538|虚线/方形；Recovery点纹|
|第三系列；Acquisition相关成本|#7267A8|点线/三角|
|Shortage|#485B70|实心|
|Procurement；Delivery|#55A3B2；#9BA5AD|分组图例|
|内层迭代|#93A6B4|短柱图|
|文字；基准线|#252C34；#7E8B95|基准虚线|

同一语义跨图保留颜色。政策与预案可分别用颜色、纹理编码，但必须说明，不靠同色暗示必然绑定。新类别用定性调色板；类别太多先考虑分组或小多图。连续热力图采用#F0F5F6、#C0DCE2、#75AAB9、#24697E单向浅深色阶；正负偏差用零居中发散色阶。类别区域不得用连续色阶。

## 尺寸与文字

- 复合图设计宽180 mm；单栏/算法图100 mm。服从实际期刊栏宽，最终插入尺寸仍需可读。
- DejaVu Sans；轴标8.5 pt、刻度8 pt、图例8 pt、子图字母10.5 pt粗体，局部放大可7 pt。不要整图缩小导致字体不可读。
- 线宽1.35 pt、标记3.8 pt、轴线0.65 pt、淡灰网格0.5 pt。默认去掉上右边框，矩阵可保留全框。
- 背景白色；只保留必要方向的网格。条形图从零起；截断纵轴需明确理由。轴标说明真实量纲。
- 数学量用mathtext斜体下标，如`$\mathit{Budget}_1$`；原论文使用Γ时服从原稿，不擅改定义。
- 金额除以1000时同步写`$10^3$ USD million`等真实单位；不能混淆million与thousand。

## 布局

图例优先图组/子图上方或真实空白处，不遮数据；按阅读顺序排列，不强制一律同位置。策略标签写完整Protection/Transfer，避免NL/P这类含混缩写。

共享横轴对齐趋势、数量和策略切换，避免双纵轴。连续数值图与类别区域图共享参数网格；逐格文字尽量去掉，区域只放必要标签，完整含义放图例。相邻格中点构成的边界不代表求出的精确连续阈值。

阴影必须说明依据和含义，不默认用它表达未定义的“切换区间”。同一个渲染器计算紧边界，再给PNG/PDF/SVG统一使用；外围约1 mm缓冲，字体自身留白可能略大。
