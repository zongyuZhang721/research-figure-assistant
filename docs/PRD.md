# PRD｜科研绘图辅助

版本 1.2 · 2026-10-21 · 产品形态：Skill + Python 工具。

## 一、问题与目标

目标用户需要在数据持续更新时生成风格一致、可复现、可核对的科研图表。首版目标是打通“CSV 输入—选图—统一绘制—核对—三格式输出”。正确性与可复用性优先于增加图形数量，首版按个人使用反馈确定范围。

## 二、方案与验收

用户提交数据、单位和比较目标；Skill 判断图形与口径，Python 执行并保存结果，经视觉核对后交付。P0 为当前核心需求，P1 为下一阶段。

| ID | 优先级 | 用户需求与功能 | 实现位置 | 验收方式 |
| --- | --- | --- | --- | --- |
| F01 | P0 | 按比较关系选图 | SKILL.md、references/chart-selection.md | 示例任务能对应趋势或其他比较关系 |
| F02 | P0 | 跨图复用视觉规则 | scripts/paper_style.py、assets/paper.mplstyle | 同源对照调用共享配置，数据值保持一致 |
| F03 | P0 | 由统一入口重画 | scripts/plot_csv.py | 六类现有图形的样例可运行 |
| F04 | P0 | 核对输入与派生数据 | scripts/plot_csv.py | 缺列、重复键、缺网格报错；保存绘图表与来源摘要 |
| F05 | P0 | 多场景使用输出 | scripts/paper_style.py | PNG 约 600 DPI；PDF、SVG 可打开且保留矢量图形 |
| F06 | P0 | 看完作品即可试用 | README.md、examples/compare.py | 文档可定位输入、调用与输出；解压后示例可运行 |
| F07 | P1 | 直接读取 Excel 与日志 | 待开发 | 先明确字段映射与异常处理，再添加入口 |

实现选择与证据位置见 [实现说明](Implementation.md)。必要输入不足时先补齐数据口径；自动校验后仍需检查轴标、图例与裁切。

## 三、效果与运营迭代

当前通过同源图形对照与样例运行检查交付；验证范围见 [验证记录](Validation.md)。试用路径设计为“README 了解问题—运行示例—替换数据—重复使用—反馈问题”，以公开示例降低理解与首次使用成本。

| 下一轮指标 | 记录方式 | 当前状态 |
| --- | --- | --- |
| 首次成功完成 | 首次尝试是否得到通过检查的输出；附失败原因 | 待试用记录 |
| 更新返工次数 | 替换数据后因样式或口径重新修改的次数 | 待真实任务记录 |
| 重复使用 | 同一试用者在后续独立任务中再次使用 | 待试用记录 |

通过 [反馈模板](../examples/feedback-template.md) 收集问题，优先修复数值错误与使用阻断，再优化样式。下一轮决策见 [复盘](Retrospective.md)。
