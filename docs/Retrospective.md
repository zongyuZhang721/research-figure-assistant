# 产品复盘｜科研绘图辅助

## 一、发现的问题

早期版本主要展示绘图规范，代码与效果虽能说明功能，却没有充分呈现为什么做、需求如何取舍、用户如何开始。个人调图经验也不足以说明其他研究者的使用成本。因此这轮把 README 改成作品入口，串联需求、PRD、实现、案例与反馈。

## 二、调整与判断

保留 Python 实现作为可复现基础，补齐同源数据对照和明确调用任务；PRD 将核心需求对应到代码与验收。先支持统一 CSV，避免同时承接多种日志和表格结构；将真实数据接入作为下一轮观察项。公开展示强调操作与证据，让阅读者能从问题走到可运行结果。

## 三、结果与下一轮

当前已形成完整文档路径、可运行对照和三格式输出。尚待解决的是首次试用者能否顺利完成字段映射，以及不同真实数据下的返工原因。下一轮邀请目标用户试用，先记录成功或阻断，再按影响程度修复；若多数问题来自字段转换，优先开发输入映射，否则继续优化图形和提示。

使用 [反馈模板](../examples/feedback-template.md) 保存“任务—问题—处理—复核”，更新 [PRD](PRD.md) 后再修订规则与脚本。效率收益由配对工时与返工记录支持。
