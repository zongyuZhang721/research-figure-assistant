# 验证与交付

核对唯一键、缺失、排序、真实网格与单位；核对成本求和、分解、比例基准、数量来源及对照条件。保存实际绘图表与转换、来源相对名称和SHA-256。公开文件不得泄露私有绝对路径。遇到重复点/缺失网格应查明，不静默平均或补0。

实际查看PNG，按需渲染PDF核对轴标、图例、字母、纹理与文字。SVG保持文本及矢量图形；PNG写600 DPI元数据。PDF/SVG矢量线条不以DPI衡量。边界自动检查不能替代视觉检查，无法证明文字彼此无重叠。

用户只要预览时给图；要复现时提供必要数据、入口、依赖，并在解压后的独立目录验证。没有执行优化时明说使用已有结果。编号变化给映射；清理旧图、缓存与无用程序。

公开HTML从白名单图片重建，重编码去掉非必要元数据。删除私有Python源码、CSV、参数JSON、压缩包入口及隐藏载荷；检查注释、脚本、链接和data URL。图片中可见数值属于用户允许公开的图片内容，不能因此声称原始数据已完全匿名。未得到公开图片授权时先确认范围。

通用脚本提供输入校验、分解、样式和导出，不代替研究判断；未实际检查时，不宣称所有期刊合规、色盲安全或完整无障碍。
