# 需求发现｜科研绘图辅助

## 一、问题现状

需求来自个人科研的重复调图经历：不同脚本的风格分散，数据更新后反复修改，图片与计算结果难以核对。核心用户是持续更新论文图表的研究者；触发场景是同一研究产生多轮数值结果，需要成组比较与多格式交付。证据来源为个人使用反馈。

## 二、需求定义

| 用户任务 | 具体障碍 | 形成的需求 |
| --- | --- | --- |
| 比较同一论文中的系列图表 | 颜色、字体和图例各自设置 | 共享样式与选图规范 |
| 替换新一轮实验数据 | 重复调图且容易漏改单位 | 固定入口与显式字段口径 |
| 检查图中结果 | 只保留图片，变换过程难追溯 | 保存实际绘图表、来源与缩放说明 |
| 论文、汇报和后续编辑 | 分别导出导致格式与边界变化 | 一次生成 PNG、PDF 和 SVG |

将需求收敛为“给定数据，生成统一且可核对的图组”。优先处理影响结果正确性和重复使用的问题，再做外观扩展；具体优先级与验收见 [PRD](PRD.md)。

## 三、预期改进

用户可以复用样式、替换输入并追溯结果，减少每张图从头设置的工作。产品价值先用同数据对照和可运行样例检查，再以真实任务的返工记录验证。需求演进与未解决问题见 [复盘](Retrospective.md)。
